# FILE MẪU — ghi chú debug (có thể xóa)

## 调试记录 / Nhật ký debug

- 现象：相机偶尔取图超时 — Hiện tượng: camera thỉnh thoảng timeout khi chụp.
- 原因：(示例) 触发信号线接触不良 — Nguyên nhân (ví dụ): dây trigger tiếp xúc kém.
- 处理：重新接线后复测 — Xử lý: đấu lại dây rồi đo lại.

Đây chỉ là nội dung ví dụ để kiểm tra hiển thị tiếng Việt và 中文 trong khung code.
